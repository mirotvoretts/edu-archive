## Утилита `stat` и работа с метаданными файлов

**Стандартная утилита `stat`** аналогична программе `02-stat` из предыдущей практики - она выводит подробную информацию о файле (метаданные):
- Размер файла
- Права доступа
- Время создания, модификации и последнего доступа
- Номер inode и другую служебную информацию

> [!note]
> `stat` полезна для отладки и анализа свойств файлов без непосредственного чтения их содержимого

## Обработка ошибок с помощью `errno`


```cpp
// Из аргументов командной строки взять имя директории
// и вывести все ее содержимое (выводить ошибки с помощью errno)

#include <stdio.h>
#include <stdlib.h>
#include <dirent.h>
#include <sys/types.h>
#include <errno.h>
#include <string.h>

int main(int argc, char** argv) {
    if (argc < 2) {
        fprintf(stderr, "directory is required\n");
        exit(1);
    }

    DIR *d = opendir(argv[1]);
    
    if (!d) {
        perror("my custom message");
        exit(1);
    }

    struct dirent *ent;
    while ((ent = readdir(d))) {
        printf("%s\n", ent->d_name);
    }

    int close_res = closedir(d);
    if (close_res == -1) {
        fprintf(stderr, "%s", strerror(errno));
        exit(1);
    }
}
```

### Альтернативные способы обработки ошибок

**1. Базовая проверка (без деталей):**

```cpp

if (!d) {
    fprintf(stderr, "some error\n");
    exit(1);
}
```

**2. Детальная обработка через switch:**

```cpp
if (!d) {
    switch(errno) {
        case ENOENT:
            fprintf(stderr, "directory <%s> not found\n", argv[1]);
            break;
        case ENOTDIR:
            fprintf(stderr, "<%s> is not a directory\n", argv[1]);
            break;
        default:
            fprintf(stderr, "some error\n");
    }
    exit(1);
}
```

**3. Использование strerror для человеко-читаемого формата:**

```cpp
if (!d) {
    fprintf(stderr, "%s\n", strerror(errno));
    exit(1);
}
```

> [!note]
> `errno` изменяется только при возникновении ошибки. Нельзя проверять ошибки конструкцией `if (errno != 0)`, так как значение может сохраниться от предыдущего вызова.

## Дублирование файловых дескрипторов: `dup` и `dup2`

```cpp
#include <fcntl.h>
#include <unistd.h>
#include <stdio.h>
#include <iostream>

void magic(int fd);

int main() {
    const char *path = "output.txt";
    int fd = open(path, O_RDWR | O_CREAT | O_TRUNC, 0644);
    if (fd == -1) { perror("open"); return 1; }

    char hello[] = "hello ";
    write(fd, hello, sizeof(hello));

    int fd_dup = dup(fd);  // Создаём дубликат файлового дескриптора
    if (fd_dup == -1) { perror("dup"); return 1; }

    char world[] = "world\n";
    write(fd_dup, world, sizeof(world));

    magic(fd);  // Перенаправляем stdout в файл
    std::cout << "I WAS PRINTED TO STDOUT" << std::endl;

    close(fd);
    close(fd_dup);
    return 0;
}

void magic(int fd) {
    dup2(fd, STDOUT_FILENO);  // STDOUT_FILENO теперь указывает на файл
}
```

**Результат работы программы:** В файле `output.txt` будет содержаться:

```
hello world
I WAS PRINTED TO STDOUT
```

## Системный вызов `access` и проверка прав доступа

```cpp
#include <unistd.h>

int access(const char *pathname, int mode);
```

**Флаги для параметра `mode` (можно комбинировать через побитовое ИЛИ):**

- `F_OK` - проверка существования файла
- `R_OK` - проверка права на чтение
- `W_OK` - проверка права на запись
- `X_OK` - проверка права на выполнение

**Пример использования:**

```cpp
char filepath[1024];
sprintf(filepath, "%s/%s", argv[1], filename);
if (access(filepath, R_OK | W_OK) == 0) {
    printf(GRN "%s\n" RESET, filepath);  // Зелёный цвет - доступ есть
} else {
    printf(RED "%s\n" RESET, filepath);  // Красный цвет - доступа нет
}
```

## Отображение файлов в память: `mmap`

```cpp
#include <stdio.h>
#include <stdlib.h>
#include <sys/mman.h>
#include <sys/stat.h>
#include <fcntl.h>
#include <unistd.h>

int main(int argc, char* argv[]) {
    if (argc < 2) {
        fprintf(stderr, "expected filename\n");
        exit(1);
    }
    char* filename = argv[1];

    int fd = open(filename, O_RDWR);
    if (fd == -1) {
        perror("can't open");
        exit(1);
    }

    struct stat st;
    if (fstat(fd, &st) == -1) {
        perror("can't stat");
        exit(1);
    }

    int input_size = st.st_size;
    void* mp = mmap(NULL, input_size, PROT_READ | PROT_WRITE, MAP_SHARED, fd, 0);
    if (mp == MAP_FAILED) {
        perror("mmap error");
        exit(1);
    }

    if (close(fd) == -1) {
        perror("error");
        exit(1);
    }

    char* data = static_cast<char*>(mp);
    printf("File before change: %s", data);

    // Изменяем файл через память
    for (int i = 0; i != input_size; ++i) {
        data[i] = '1';
    }

    if (munmap(mp, input_size) == -1) {
        perror("error");
        exit(1);
    }

    return 0;
}
```

### Флаги защиты (`prot`):

- `PROT_NONE` - страницы недоступны
- `PROT_READ` - страницы доступны для чтения
- `PROT_WRITE` - страницы доступны для записи
- `PROT_EXEC` - страницы доступны для выполнения

### Флаги отображения (`flags`):

- `MAP_SHARED` - изменения видны другим процессам
- `MAP_PRIVATE` - изменения приватны для процесса

## Идентификатор процесса (PID) и его использование

### Что такое PID?

**PID (Process ID)** - это уникальный числовой идентификатор, который операционная система присваивает каждому процессу при его создании. Это основной способ идентификации процессов в системе.

### Как посмотреть PID?

#### Командная строка:

```bash
ps -u username        # Все процессы пользователя
ps aux | grep имя_процесса  # Поиск по имени процесса
```

**Пример вывода:**

```
PID  TTY          TIME CMD
1234 pts/0    00:00:00 bash
5678 pts/0    00:00:01 my_program
9012 pts/0    00:00:00 ps
```

#### В программе на C/C++:

```cpp
#include <unistd.h>
#include <stdio.h>

int main() {
    printf("Мой PID: %d\n", getpid());
    printf("PID родителя: %d\n", getppid());
    return 0;
}
```

### Практический пример

```cpp
#include <unistd.h>
#include <sys/syscall.h>
#include <iostream>

int main() {
    const char message[] = "Hello, World! (using syscall)\n";
    size_t length = sizeof(message) - 1;
    syscall(SYS_write, STDOUT_FILENO, message, length);

    // Пауза для возможности посмотреть PID процесса
    int dummy = 0;
    std::cout << "Мой PID: " << getpid() << std::endl;
    std::cout << "Нажмите Enter для продолжения...";
    std::cin >> dummy;

    char* m1 = new char[100000];
    char* m2 = new char[10000000];

    std::cout << "Нажмите Enter для завершения...";
    std::cin >> dummy;

    return (m1[900] - m2[9999999]);
}
```

### Мониторинг процесса по PID

После запуска программы можно отслеживать её состояние:

```bash
# Найти PID процесса
ps -u user | grep 02-new.elf

# Просмотреть информацию о памяти процесса
cat /proc/5678/status | grep -E "(VmSize|VmRSS)"

# Просмотреть карту памяти процесса
cat /proc/5678/maps

# Мониторинг в реальном времени
watch -n 1 'cat /proc/5678/status | grep -E "(VmSize|VmRSS)"'
```
