# Конспект
## 1. Генерация случайных чисел

### Функция `random_create`

Функция `random_create` (или аналогичная, например `rand()`, `random()`) используется для создания генератора псевдослучайных чисел. Она не создаёт «настоящие» случайные значения, а использует математическую формулу, дающую _псевдослучайную последовательность_.

### Сид (seed, зерно)

**Seed** - это начальное значение генератора. При одинаковом зерне последовательность псевдослучайных чисел всегда одинакова:

```c
srand(42);   // установка зерна
int x = rand();  // всегда выдаст одинаковый результат при том же seed
```

Чтобы получать разные последовательности, обычно используют текущее время:

```c
srand(time(NULL));
```

### Псевдослучайность и линейный конгруэнтный генератор (ЛКГ)

Псевдослучайные числа получаются по формуле **линейного конгруэнтного генератора**:

$$ X_{n+1} = (aX_n + c) \mod m $$

Где:

- `a` - множитель,
- `c` - приращение,
- `m` - модуль,    
- `X_0` - зерно (seed).

Это простой и быстрый метод, но он не обеспечивает криптографической стойкости. Для безопасных генераций применяются специальные алгоритмы (например, `/dev/urandom`, Mersenne Twister, или библиотеки OpenSSL).

## 2. Кодировки символов и локаль

### Что такое кодировка

**Кодировка** определяет, как символы (буквы, цифры, знаки) представляются в памяти и передаются между устройствами в виде байтов. В Си текстовые данные передаются в терминал байт за байтом, а **терминал** уже решает, как эти байты отображать, исходя из текущей **локали**.

### Локаль (locale)

**Локаль** - это набор региональных настроек, определяющих язык, страну, денежные единицы, формат времени, дату и кодировку.

- Проверить текущие настройки можно командой:
    ```bash
    locale
    ```
- Пример настроек: `LANG=ru_RU.UTF-8` означает русскую локаль с кодировкой UTF-8.

### История кодировок

#### ASCII (American Standard Code for Information Interchange)

- Диапазон: 0–127 (7 бит)
- Содержит латинские буквы, цифры, знаки препинания и управляющие символы.
- Каждый символ занимает **1 байт**.

Проблема: отсутствуют национальные символы (например, кириллица, иероглифы).

```c
#include <stdio.h>

int main() {
    char str[] = {0x48, 0x69, '\0'};

    printf("%s\n", {0x48, 0x69, '\0'});
    printf("%lu\n", sizeof(str)); // Hi
}
```

> [!note]
> Когда ASCII создавался в 1960-х, большинство коммуникационных устройств (телетайпы, терминалы) работали с **7-битной передачей данных**, потому что это экономило место и упрощало оборудование.
> 
> Однако память и каналы передачи информации всё равно хранили данные в **байтах по 8 бит** - это была минимальная единица хранения и пересылки. Поэтому **8-й бит оставался свободным**.
> 
> Со временем этот «лишний» бит начали использовать для разных целей...

#### CP1251 и KOI8-R

- При расширении ASCII использовали 8 бит (0–255). Вторая половина таблицы (128–255) использовалась для национальных символов.
- **CP1251** - кодировка Windows для кириллицы.
- **KOI8-R** - кодировка, где русские буквы расположены так, чтобы при потере старшего бита (например, в ASCII-терминале) текст оставался частично читаемым (буквы превращались в латиницу с похожим расположением).
    - Это была «фишка» KOI8-R - удобство при передаче через старые ASCII-каналы.

```c
#include <stdio.h>

int main() {
    char str[] = {0xF0, 0xD2, 0xC9, 0xD7, 0xC5, 0xD4, '\0'};

    printf("%s\n", str);
    printf("%lu\n", sizeof(str));


    for (int i = 0; i < sizeof(str); ++i) {
        str[i] &= 0x7f;
    }

    printf("%s\n", str); // Привет
    printf("%lu\n", sizeof(str));
}

/*
0111 1111
*/
```

#### Unicode и кодпоинты

- Unicode - универсальный стандарт кодирования символов всех языков мира.
- Каждый символ имеет **кодпоинт** (числовой идентификатор), например:
    - `'A'` → U+0041
    - `'Я'` → U+042F
- Символы могут иметь разное представление в зависимости от кодировки Unicode (UTF-8, UTF-16, UTF-32).

#### BOM (Byte Order Mark)

- **BOM** (U+FEFF) - специальный невидимый символ, указывающий порядок байтов в многобайтовых кодировках.

## 3. UTF-8, UTF-16 и UTF-32

### UTF-8

- Универсальная кодировка, совместимая с ASCII.
- Символ кодируется от **1 до 4 байт**.
- Символы ASCII (0–127) остаются теми же - это обеспечивает обратную совместимость.

Преимущества:
- Экономия памяти для латиницы (1 байт на символ);
- Совместимость с ASCII и большинством старых программ;
- Отсутствие проблем с порядком байтов (endian).

Недостаток:
- Непостоянная длина символа - усложняет прямой доступ к элементам строки.

```c
#include <stdio.h>

int main() {
    // unicode
    // https://symbl.cc/en/unicode-table/#cyrillic
    // ё --- u+0451

    // utf-8
    // 1 byte,  7 bit,  0xxx xxxx
    // 2 byte, 11 bit,  110xxxxx 10xxxxxx
    // 3 byte. 16 bit,  1110xxxx 10xxxxxx 10xxxxxx
    // 4 byte. 21 bit,  11110xxx 10xxxxxx 10xxxxxx 10xxxxxx

    // ё --- u+0451
    // 00000100 01010001 => 11 значящих ###=> 2 byte, 11 bit,  110xxxxx 10xxxxxx
    // 11010001 10010001 utf-8
    // 0xd1 91
    char str[] = {0xd1, 0x91, '\0'};
    printf("%s\n", str);
    printf("%lu\n", sizeof(str));

    // ё = е + ..
    // u+0435 u+0308
    char str1[] = {0xd0, 0xb5, 0xcc, 0x88, '\0'};
    printf("%s\n", str1);
    printf("%lu\n", sizeof(str1));

    // U+1FA77 -- heart
    char str2[] = {0xf0, 0x9f, 0xa9, 0xb7, '\0'};
    printf("%s\n", str2);
    printf("%lu\n", sizeof(str2));


    char str3[] = {0xf0, 0x9f, 0x91, 0xa8, '\0'};
    printf("%s\n", str3);
    printf("%lu\n", sizeof(str3));

    char str4[] = {0xf0, 0x9f, 0x91, 0xa8, 0xf0, 0x9f, 0x8f, 0xbd, 0x0a, '\0'};
    printf("%s\n", str4);
    printf("%lu\n", sizeof(str4));
}
```

### UTF-16 и UTF-32

- **UTF-16**: 2 или 4 байта на символ.
- **UTF-32**: всегда 4 байта на символ (фиксированная длина).

Сравнение:

|Кодировка|Длина символа|Совместимость с ASCII|Использование|
|---|---|---|---|
|UTF-8|1–4 байта|✅ Полная|UNIX/Linux, интернет|
|UTF-16|2–4 байта|❌ Нет|Windows, Java|
|UTF-32|4 байта|❌ Нет|внутренние представления|

**Вывод:** UTF-8 оптимальна для текстов с преобладанием латиницы и для взаимодействия между системами.

## 4. Работа с широкими символами (`wchar_t`, `wstring`)

### `wchar_t`

- Тип данных, предназначенный для хранения символов Unicode в виде числовых кодпоинтов.
- Размер зависит от платформы:
    - 2 байта на Windows (UTF-16)
    - 4 байта на Linux (UTF-32)

Пример:

```c
wchar_t ch = L'Я';
wprintf(L"%lc\n", ch);
```

### `wstring`

- Широкая версия строки (`std::wstring`) для работы с `wchar_t`.
- Используется, когда стандартная `std::string` не подходит для Unicode-текста.

Однако современные практики чаще рекомендуют использовать `std::u8string`, `std::u16string`, `std::u32string` для явного контроля кодировки.

```c
#include <wchar.h>
#include <stddef.h>
#include <locale.h>

int main() {
    // Устанавливаем локаль для программу равную <<локали>> в системе
    setlocale(LC_ALL, "");

    // Unicode-символ 'Я' имеет код U+042F
    wchar_t my_char = L'\u042f';

    // wprintf преобразует utf-32 в utf-8, т.к. я установил locale для программы как
    // равную <<локали>> в системе (т.е. в utf-8)
    wprintf(L"%lc %d\n", my_char, sizeof(wchar_t));

    return 0;
}
```
