# Конспект

## 1. Структура программы на ассемблере

Программа на ассемблере состоит из нескольких секций, определяющих разные типы данных и инструкций:

### `.text`

Секция, в которой располагается исполняемый код программы. Именно отсюда процессор начинает выполнение инструкций. Здесь объявляется метка `main` - точка входа программы.

### `.data`

Секция, в которой хранятся инициализированные данные, такие как числа, строки и другие переменные.

Пример:

```asm
.intel_syntax noprefix
.global main
.text

main:
    mov qword ptr [rip + var], 500      ; rip - адрес текущей инструкции
    mov rdi, [rip + var]                ; загрузка значения из памяти
    call writei64
    call finish

.data
var:
    .quad 42                            ; переменная var со значением 42
```

### Почему используется RIP-смещение

RIP (Instruction Pointer) указывает на текущую исполняемую инструкцию. Смещение относительно RIP (`[rip + var]`) позволяет обращаться к данным независимо от того, где программа будет загружена в память. Это обеспечивает **позиционно-независимый код (PIC)**, необходимый для работы современных операционных систем.

### Инструкция `lea`

Инструкция `lea` (_load effective address_) загружает в регистр адрес, а не значение по адресу. Часто используется для арифметики с указателями:

```asm
lea rax, [rip + var] ; загрузить адрес var в rax
```

## 2. Работа с переменными

Пример из `01-variable.S` показывает простое использование переменной и демонстрирует различие между секциями `.text` и `.data`:

```asm
.intel_syntax noprefix
.global main
.text
main:
    mov     qword ptr [var + rip], 500
    mov     rdi, [var + rip]
    call    writei64
    call    finish

// В таком коде var находится в секции .text - изменять её нельзя.
// Чтобы var можно было модифицировать, нужно поместить в .data.

.data
var:
    .quad 42
```

### Размеры данных

|Директива|Размер|Тип указателя|
|---|---|---|
|`.byte`|1 байт|`byte ptr`|
|`.word`|2 байта|`word ptr`|
|`.int`|4 байта|`dword ptr`|
|`.quad`|8 байт|`qword ptr`|

## 3. Массивы и индексация

Файл `02-array.S` демонстрирует работу с массивами и использование базового адреса, индекса и масштабирующего множителя (_SCALE_):

```asm
.intel_syntax noprefix
.global main

main:
    call    readi64         ; читаем индекс → r12
    mov     r12, rax

    call    readi64         ; читаем новое значение → r13
    mov     r13, rax

    ; адрес массива
    lea     r14, [rip + arr]
    ; адрес ячейки arr[r12]
    lea     r14, [r14 + 8 * r12]

    mov     rdi, [r14]      ; читаем значение элемента
    call    writei64        ; выводим его

    mov     [r14], r13      ; записываем новое значение
    jmp     main

.bss
arr:
    .skip 200 * 8           ; массив из 200 8-байтных чисел
```

### Адресация `[base + index * scale + disp]`

- **base** - базовый регистр (например, `r14`)
- **index** - индексный регистр (`r12`)
- **scale** - множитель (1, 2, 4 или 8)
- **disp** - смещение (например, `rip + arr`)

Такой формат удобен для обращения к элементам массива.

## 4. Ввод и вывод

Библиотека `simpleio_x64_64.S` предоставляет удобные функции для работы с числами:

|Функция|Назначение|Регистр|
|---|---|---|
|`readi32`|Считать 32-битное число|Результат в `eax`|
|`readi64`|Считать 64-битное число|Результат в `rax`|
|`writei32`|Напечатать 32-битное число|Аргумент в `edi`|
|`writei64`|Напечатать 64-битное число|Аргумент в `rdi`|

Пример из `01-read_write.S`:

```asm
.intel_syntax noprefix
.global main

main:
    call readi64        ; ввод числа в rax
    mov rdi, rax        ; передача числа для вывода
    call writei64       ; печать результата
    call finish
```

Библиотечные функции **не изменяют регистры**: `rsp`, `rbp`, `rbx`, `r12`–`r15`.

## 5. Арифметические операции

Пример из `02-arithmetic-ANSWER.S` показывает сложение двух чисел:

```asm
call readi64
mov  r12, rax       ; первое число
call readi64
mov  r13, rax       ; второе число
add  r12, r13       ; сложение
mov  rdi, r12
call writei64       ; вывод результата
call finish
```

### Основные арифметические инструкции

|Инструкция|Описание|
|---|---|
|`add DST, SRC`|DST += SRC|
|`sub DST, SRC`|DST -= SRC|
|`inc DST`|Увеличение на 1|
|`dec DST`|Уменьшение на 1|
|`neg DST`|DST = -DST|
|`imul SRC`|Знаковое умножение|
|`mul SRC`|Беззнаковое умножение|
|`cmp DST, SRC`|Сравнение DST - SRC (результат не сохраняется)|
|`test DST, SRC`|Побитовое И без сохранения результата|

## 6. Флаги процессора

При выполнении арифметических операций процессор изменяет **флаги состояния**:

- **ZF (Zero Flag)** - результат равен нулю.
- **SF (Sign Flag)** - результат отрицателен.
- **CF (Carry Flag)** - перенос при беззнаковом переполнении.
- **OF (Overflow Flag)** - переполнение при знаковом переполнении.

Флаги позволяют выполнять условные переходы после инструкций `cmp` и `test`.

---

## 7. Условные переходы

|Инструкция|Условие|
|---|---|
|`jz label`|если ZF = 1 (равно нулю)|
|`jnz label`|если ZF = 0 (не равно нулю)|
|`jc label`|если CF = 1 (перенос)|
|`jg label`|больше (для знаковых)|
|`jl label`|меньше (для знаковых)|
|`ja label`|больше (беззнаковых)|
|`jb label`|меньше (беззнаковых)|

Пример фрагмента из `conditions.S`:

```asm
sub r12, r13
jz  end
jl  print_less
jmp print_greater
```

## 8. Сдвиги и циклические операции

Сдвиги используются для быстрого умножения и деления на степени двойки, а также для обработки битовых масок.

|Инструкция|Назначение|
|---|---|
|`shl`|Логический сдвиг влево (CF = старший бит)|
|`shr`|Логический сдвиг вправо (CF = младший бит)|
|`sal`|Арифметический сдвиг влево (эквивалентен `shl`)|
|`sar`|Арифметический сдвиг вправо (с сохранением знака)|
|`rol`|Циклический сдвиг влево|
|`ror`|Циклический сдвиг вправо|

Пример из `shifts.S`:

```asm
call readi64
mov r12, rax

m_shl:
    shl r12, 1
    jnz m_shl

m_shr:
    shr r12, 1
    jnz m_shr

call finish
```

## 9. Отладка в GDB

Для отладки ассемблерных программ используется **GDB**.

### Компиляция

```bash
gcc -g prog.S simpleio_x64_64.S -o prog
```

### Основные команды

- `break main` - установить точку останова.
- `run` - запустить программу.
- `step` / `next` - пошаговое выполнение.
- `layout regs` - показать регистры.
- `p/z $rax` - вывести содержимое регистра в шестнадцатеричном виде.
- `set $rax=5` - задать значение регистра.

Чтобы включить **Intel-синтаксис**:

```bash
echo "set disassembly-flavor intel" > .gdbinit
```
